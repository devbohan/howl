# デモ用ダミーデータ / Demo data

**このディレクトリの中身は本番ビルドに入りません。**

`VITE_DEMO=1` のときだけ読み込まれます。`npm run build` / `npm run build:static`
は環境変数を立てないので、ここに何を書いても静的出力には現れません。

理由は [REQUIREMENTS.md](../../../REQUIREMENTS.md) の R1.6 / R1.7 / R1.9 ——
一度、実在する企業名を冠した架空のニュースと、架空の投票数が本番に載りかけた。
「消し忘れ」を運用ルールではなくビルドの仕組みで防ぐのが、この分離の目的。

```bash
npm run dev:demo     # ダミーデータありで開発サーバー
npm run dev          # 実データのみ
```
